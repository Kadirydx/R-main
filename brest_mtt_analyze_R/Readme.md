# Breast Cancer Analysis 

## About the Project
This project involves the statistical analysis and exploration of breast cancer data. The analysis was conducted using R and compiled into a dynamic, interactive HTML report via R Markdown. The primary focus is on Exploratory Data Analysis (EDA) and interpreting the underlying patterns within the medical dataset.

##  Technologies Used
* **R:** Statistical computing and data analysis
* **R Markdown:** Dynamic document generation and reproducible research
* **HTML/Pandoc:** Rendering the final interactive report (`Brest_Cancer_Analyze.html`)

##  Key Features
* **Exploratory Data Analysis (EDA):** Detailed statistical breakdown of the dataset.
* **Data Visualization:** Generating plots and graphs to understand feature distributions.
* **Interactive Reporting:** A fully structured HTML output with code folding and a floating Table of Contents (TOC) for easy navigation...
