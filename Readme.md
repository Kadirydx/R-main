#  Data Science & Statistical Reporting Portfolio

This projects featured in this repository were developed exclusively for educational purposes. My primary goal in building these projects was to learn, practice, and refine **advanced data reporting techniques** and **code-level statistical analysis**. 

Rather than presenting medically or academically binding results, these repositories serve as a practical coding playground. They demonstrate my hands-on progression in writing clean code, structuring dynamic and interactive reports (using R Markdown and Shiny), and programmatically executing robust statistical tests on diverse datasets.

---

##  Projects Overview

### 1. [MTT Assay Data Analysis & Visualization App]
*An interactive R Shiny web application built to streamline laboratory cell viability analysis.*
* **Tech:** R, Shiny, JavaScript, `rhandsontable`, `readxl`
* **Highlight:** Features automated statistical quality control, outlier detection with visual JavaScript flags, and dynamic time-course tracking for complex 96-well plate layouts.

### 2. [Socio-Economic and Health Data Analysis]
*A comprehensive statistical study on the impact of lifestyle and socio-economic factors on physical health and depression.*
* **Tech:** R, R Markdown, `dplyr`, `ggplot2`
* **Highlight:** Complex data wrangling that successfully merges five distinct raw datasets, followed by robust hypothesis testing (ANOVA, Tukey's HSD, Regression).

### 3. [Breast Cancer Statistical Analysis]
*Statistical exploration and interactive reporting on tumor characteristics.*
* **Tech:** R, R Markdown, HTML/Pandoc
* **Highlight:** In-depth Exploratory Data Analysis (EDA) and correlation tracking to identify patterns differentiating malignant and benign structures.

### 4. [Sleep Duration & Alzheimer's Pathology (FE418)]
*A biostatistical study examining the relationship between sleep patterns and cognitive pathology scores.*
* **Tech:** R, Custom R Functions, CSS
* **Highlight:** Implementation of custom data validation scripts (`check_fun`, `custom_summary`) and rigorous Independent T-tests.

### 5. [Overweight Reasons Analysis]
*Investigating genetic and lifestyle factors contributing to obesity levels.*
* **Tech:** R, R Markdown
* **Highlight:** Statistical validation using Chi-Square tests for independence across diverse categorical variables.
