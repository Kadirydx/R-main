# Sleep Duration & Alzheimer's Pathology Analysis 

## About the Project
This biostatistical research project (FE418) investigates the potential relationship between sleep duration and Alzheimer's pathology scores. Developed using R and compiled into an interactive HTML report via R Markdown, the study employs custom-built data validation functions and rigorous statistical tests. By categorizing participants into "high" and "low" sleep duration groups based on the mean, the project aims to uncover statistically significant differences in cognitive/pathological health outcomes.

##  Technologies Used
* **R:** Statistical computing, custom function development, and hypothesis testing.
* **R Markdown:** Dynamic document generation for reproducible research.
* **HTML/CSS:** Rendering the final interactive analytical report with a custom stylesheet (`renk.css`).

##  Key Features
* **Custom Data Validation:** Implementation of unique functions (e.g., `check_fun`, `custom_summary`) to verify data integrity, handle duplicates, and calculate precise descriptive statistics (mean, median, mode).
* **Data Segmentation:** Dynamically categorizing the dataset into low and high sleep duration groups for comparative analysis.
* **Statistical Testing:** Conducting robust statistical evaluations, including Shapiro-Wilk tests for normality, correlation matrices, and Independent T-tests to compare Alzheimer's scores across groups.
* **Interactive Reporting:** A fully structured HTML output featuring code folding and a floating Table of Contents (TOC) for seamless navigation.
