# Overweight Reasons Analysis 

## About the Project
This project explores the various genetic and lifestyle factors contributing to overweight and obesity levels. Developed using R and compiled into an interactive HTML report via R Markdown, the study conducts an in-depth Exploratory Data Analysis (EDA) on a diverse dataset. The primary objective is to statistically validate hypotheses, such as the impact of genetic background and gender on obesity, using tests like the Chi-Square Test for Independence.

##  Technologies Used
* **R:** Statistical computing, data manipulation, and hypothesis testing
* **R Markdown:** Dynamic document generation and reproducible research
* **ggplot2 / dplyr:** Advanced data visualization and data wrangling
* **HTML/Pandoc:** Rendering the final interactive report (`overweight.html`)

##  Key Features
* **Extensive Data Manipulation:** Cleaning and structuring variables (e.g., BMI calculation, renaming columns) for accurate modeling.
* **Exploratory Data Analysis (EDA):** Visualizing feature distributions and relationships using boxplots, bar charts, and scatter plots.
* **Hypothesis Testing:** Applying Chi-Square Tests to determine the statistical significance between variables like family history, gender, and obesity types.
* **Interactive Reporting:** A fully structured HTML output featuring code folding and a floating Table of Contents (TOC) for seamless navigation.
