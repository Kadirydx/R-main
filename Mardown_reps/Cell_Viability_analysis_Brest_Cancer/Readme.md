# Breast Cancer Statistical Analysis 

## About the Project
This project focuses on the statistical exploration, visualization, and analysis of breast cancer data. Developed entirely in R and compiled into a comprehensive, interactive HTML report via R Markdown, this study aims to uncover underlying patterns in tumor characteristics. By conducting in-depth Exploratory Data Analysis (EDA) and statistical testing, the project provides valuable insights into the key features that differentiate malignant and benign cases.

##  Technologies Used
* **R:** Advanced statistical computing, data manipulation, and modeling
* **R Markdown:** Dynamic document generation for reproducible research
* **ggplot2 & dplyr:** Tidyverse tools for extensive data wrangling and high-quality visualizations
* **HTML/Pandoc:** Rendering the final interactive analytical report (`Brest_Cancer_Analyze.html`)

##  Key Features
* **Exploratory Data Analysis (EDA):** Detailed statistical breakdown of medical features (e.g., cell radius, texture, perimeter, area).
* **Advanced Data Visualization:** Utilization of correlation matrices, boxplots, and density plots to understand feature distributions and multicollinearity.
* **Data Preprocessing:** Cleaning, structuring, and preparing the medical dataset for accurate statistical interpretation.
* **Interactive Reporting:** A fully structured HTML output featuring code folding, dynamic formatting, and a floating Table of Contents (TOC) for seamless navigation.
